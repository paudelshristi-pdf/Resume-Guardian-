# Resume-Guardian-
An AI-powered tool that analyzes resumes and job descriptions, highlights matching skills, and explains potential gaps to help job seekers find relevant roles.

Built for job seekers who want to check how well their resume matches a specific job posting *before* they apply — surfacing which skills already align and which ones are missing.

Unlike simple keyword matching, Resume Guardian uses sentence embeddings to compare the *meaning* of resume content and job requirements — so it can recognize that "led a team of 5 engineers" relates to "management experience" even without exact word overlap.
